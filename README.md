# คืนหอนหลอนหมาป่า 🐺

ผู้ช่วยผู้ดำเนินเกม **Werewolf (หมาป่า)** สำหรับใช้บนมือถือเครื่องเดียว — คนเป็นเกมเปิดดูบทบาทของตัวเองทีละคนได้เองผ่านหน้าจอ ไม่ต้องแจกการ์ด ไม่มีสปอยล์

- **ใช้งาน:** https://werewolf.phetsamaisdv.workers.dev
- **สถานะโปรเจค / สิ่งที่ทำแล้ว / ยังไม่ได้ทำ:** [`PROJECT.md`](PROJECT.md)
- **Checklist ทดสอบจริงบนมือถือ:** [`TESTING.md`](TESTING.md)

## ฟีเจอร์

- บทบาทครบ **32 บท** + เอฟเฟกต์ครบ (หมาป่า 5 / ชาวบ้าน 21 / กลาง 5 + ชาวบ้านธรรมดา) รวมระบบใหม่: การตายเลื่อนเวลา (นักเลง/แวมไพร์), ปิดปาก (นักเวท), บังคับโหวต (ตัวป่วน), ลัทธิ, แวมไพร์, นักเลง, ผู้ขายหนัง, ผู้หยั่งรู้ฝึกหัด ฯลฯ
- **ระบบชนะ 11 แบบ** — ชาวบ้าน / หมาป่า / คู่รัก / คนโง่ / ผู้ขายหนัง / ลัทธิ / นักเลง / หมาป่าโดดเดี่ยว / แวมไพร์ + parity
- ครบทุกเฟสเกม **13 หน้า**: ตั้งค่า → จัดบทบาท → กลางคืน → รุ่งเช้า → กลางวัน → โหวต → เสมอ → แขวนคอ → จบเกม
- **โหวต** พร้อมนายอำเภอเสียง x2, คะแนนเสมอโหวตใหม่, สรุปคะแนน + รายชื่อคนยังไม่โหวต
- ระบบชนะครบทุกเคส + **Undo ได้ทุกจุด** (กลางคืน / แขวนคอ / โหวต)
- **3 ช่องบันทึกเกม** + ประวัติ **10 เกมล่าสุด** + resume กลับเฟสเดิมหลังสลับช่อง
- **Preset ชุดบทบาท** (มาตรฐาน / Party / Competitive ตามจำนวนผู้เล่น) + บันทึกชุดเองได้
- เสียงแจ้งเตือน 4 แบบ (Web Audio) · ธีม dark/light · จับเวลา · Wake Lock · Haptic
- **Error boundary** — render พังแล้วแสดงหน้าข้อความ + ปุ่มกู้คืน แทนหน้าขาว
- **PWA** — ติดตั้งลงหน้าจอหลัก + ใช้งานออฟไลน์ได้

## เริ่มต้น

ไม่มีขั้นตอน build เปิดผ่าน dev server อย่างเดียว:

```
npm run serve
```

แล้วเปิด http://127.0.0.1:8123/

## คำสั่ง

| คำสั่ง            | ทำอะไร                                                               |
| ----------------- | -------------------------------------------------------------------- |
| `npm run serve`   | dev server ที่ `127.0.0.1:8123` (ใช้ทดสอบ PWA/ออฟไลน์)               |
| `npm test`        | E2E **71 checks** ผ่าน Chrome DevTools Protocol (ต้องมี Chrome/Edge) |
| `npm run check`   | `eslint .` + `prettier --check .` — รันก่อน commit เสมอ              |
| `npm run lint`    | ESLint อย่างเดียว                                                    |
| `npm run format`  | Prettier เขียนทับไฟล์ที่ format ไม่ตรง                               |
| `npm run preview` | `wrangler dev` — จำลอง Workers บนเครื่อง                             |
| `npm run deploy`  | deploy ขึ้น Cloudflare Workers                                       |

## ข้อมูลเก็บอยู่ที่ไหน

ทั้งหมดอยู่ใน `localStorage` ของเครื่องนั้น ๆ **ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งข้อมูลออก**:

| คีย์                                | เนื้อหา                |
| ----------------------------------- | ---------------------- |
| `werewolf_v9`                       | ช่องบันทึกเกมที่ 1     |
| `werewolf_v9_s2` / `werewolf_v9_s3` | ช่องบันทึกเกมที่ 2 / 3 |
| `werewolf_slot_idx`                 | ช่องที่กำลังใช้งาน     |
| `werewolf_history`                  | ประวัติ 10 เกมล่าสุด   |
| `werewolf_presets`                  | ชุดบทบาทที่บันทึกไว้   |

ถ้าบันทึกไม่สำเร็จ (พื้นที่เต็ม หรือเบราว์เซอร์บล็อกในโหมดส่วนตัว) แอปจะเตือนครั้งเดียวตอนเกิดครั้งแรก + แสดง `⚠️ บันทึกไม่สำเร็จ` ที่หน้าแรก

### กฎเวอร์ชันข้อมูล (Save schema)

| ตัวแปร        | ความหมาย                                         | เปลี่ยนเมื่อไหร่                                                                                |
| ------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `SAVE_KEY`    | ชื่อคีย์ใน `localStorage`                        | **เปลี่ยนเฉพาะตอนตั้งใจล้างข้อมูลผู้ใช้เก่าทิ้งเท่านั้น** — เปลี่ยนเมื่อไหร่ของเก่าจะอ่านไม่ได้ |
| `VER`         | เวอร์ชันแอป (ตรงกับ `version` ใน `package.json`) | ทุกครั้งที่ปล่อยของใหม่ — ใช้แสดงบน UI                                                          |
| `SAVE_SCHEMA` | เวอร์ชันโครงสร้าง payload ที่บันทึก              | **+1 ทุกครั้งที่ shape ของ save data เปลี่ยน** (เพิ่ม/ลบ/ย้าย field)                            |

เมื่อ `SAVE_SCHEMA` +1 ให้เพิ่มบล็อกใหม่ใน **`migrateSave()`** (app.js) เพื่อยกข้อมูลจาก schema เก่าขึ้นมา — `load()` เรียกมันก่อนเอาไปใช้เสมอ จึงโหลด save เก่าได้โดยไม่พัง

## Deploy

Cloudflare Workers (static assets ล้วน ไม่มี Worker code):

```
npm run deploy
```

- ตั้งค่าอยู่ใน `wrangler.jsonc` (`assets.directory: "."`) + `.assetsignore` ตัดไฟล์ development ออก
- ⚠️ **ห้ามลบ `.assetsignore`** — `node_modules` (workerd ~127MB) เกินโควตา 25MB ของ Workers แล้ว deploy จะพัง
- `$schema` ชี้ไฟล์ใน `schemas/` ซึ่งถูกกันไม่ให้อัปขึ้น Workers แล้ว

## Dependency

โค้ดที่ deploy **ไม่มี dependency เลย** — `devDependencies` (ESLint + Prettier) ใช้เฉพาะตอน develop บนเครื่อง และถูก `.assetsignore` กันไม่ให้อัปขึ้น Workers
